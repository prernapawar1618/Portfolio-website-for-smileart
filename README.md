# Smile Art Photography — Portfolio Website

A bespoke, cinematic, photography-first editorial portfolio website designed and developed for **Smile Art Photography** (Photographer: **Harshal Mahajan**), conceived as a private client concept project by **AmbiVision**.

## Visual Design & Aesthetics

Inspired by contemporary editorial luxury (`starlinecreative.co/sutej-pannu`):
- **Palette:** Warm Ivory (`#F7F3ED`), Deep Charcoal (`#121212`), Soft Cream (`#EAE2D7`), Muted Taupe (`#A99B8C`), Champagne Gold (`#C5A880`)
- **Typography:** *Cormorant Garamond* (Fine-Art Editorial Serif) and *Plus Jakarta Sans* (Modern Sans-Serif)
- **Layout:** Asymmetric grids, generous whitespace, full-bleed hero, and minimalist floating navigation.

## Features

- **Cinematic Homepage:** Full-screen photographic hero, brand storytelling, curated preview, services highlight, Harshal Mahajan's profile, live Instagram discovery, and booking CTA.
- **Interactive Portfolio:** Category filtering (*Wedding*, *Pre-Wedding*, *Bridal Portraits*, *Celebrations & Haldi*) with responsive masonry grid and full-screen lightbox (keyboard & touch navigation).
- **Verified Services:** 6 offerings including Wedding Photography, Pre-Wedding, Bridal & Couple Portraits, Haldi/Mehendi Celebrations, Cinematic Films, and Custom Invitation Art.
- **Authentic About Page:** Grounded in Harshal Mahajan's verified work, Canon R6 Mark cinema setup, and Burhanpur studio base.
- **Booking Interface:** Validated enquiry form with technical backend notice and direct instant WhatsApp / Instagram DM fallback actions.
- **SEO & Performance:** Next.js 15 App Router, static page generation, OpenGraph metadata, sitemap.xml, and robots.txt.

## Tech Stack

- **Framework:** Next.js 15 (App Router, React 19)
- **Styling:** Tailwind CSS
- **Motion:** Framer Motion
- **Icons:** Lucide React & Custom SVG
- **Language:** TypeScript

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   npm start
   ```
